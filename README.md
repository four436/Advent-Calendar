# Advent Calendar
Acest proiect a fost coceput pentru un proiect la germană, in clasa a X-a, anul 2023. Cerința fiind un advent calendar cu coate zilele lunii Decembrie, fiecare zi din calendar menționează un citat spus de mari personalități.
## Dependințe
#### Limbajul folosit pentru realizarea programului:  
  * Java
#### Librăriile folosite:  
  * javax.sound.sampled
    - folosit pentru a putea pune melodia de background
  * javax.swing
  * java.awt
    - folosite pentru realizarea interfaței grafice
  * java.io
    - folosit pentru a putea pune ca background un fișier .gif
## Descrierea interfeței
La rularea programului se deschide o fereastră care contine o pagină de calendare a lunii Decembrie sub forma de tabel/matrice, pe prima linie se află zilele săptămânii, pe urmatoarele linii se flă zilele corespunzatoare fiecărei zile. În josul paginii se află un buton care perimite schimbarea limbii în care este scris texul (Română/Germană). Dată din luna decembrie este un buton care te redirecționează la o noua pagină care afișează câte un citat spus de o mare personalitate în limba în care este setat programul.
