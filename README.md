# Advent Calendar
Acest proiect a fost coceput pentru un proiect la germană, in clasa a X-a, anul 2023. Cerința fiind un advent calendar cu coate zilele lunii Decembrie, fiecare zi din calendar menționează un citat spus de mari personalități.
## Dependințe
#### Limbajul folosit pentru realizarea programului:  
  * Java
#### Librăriile folosite:  
  * javax.sound.sampled
    - folosit pentru a putea pune melodia de background
  * javax.swing
  * java.awt
    - folosite pentru realizarea interfaței grafice
  * java.io
    - folosit pentru a putea pune ca background un fișier .gif
